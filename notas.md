# Notas do Projeto Inventário CLI

## 📌 Descrição
Sistema de gerenciamento de inventário via linha de comando (CLI), com suporte a cadastro de produtos e categorias. Desenvolvido em TypeScript, usando TypeORM e SQLite como banco de dados.
